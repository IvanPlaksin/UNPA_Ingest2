# unpa-import

Standalone CLI for importing **UNPA Graph Packages** (`*.ugp.tar.gz`) into a target
Memgraph (+ Qdrant). Companion to the platform's Graph Transfer exporter
(`/api/v1/graph-transfer`). Runs on bare Ubuntu via `npm ci` — no Docker required.

## Install

```bash
cd tools/unpa-import
npm ci        # or: npm install
```

> **Shared library.** The importer uses the same serialization library as the
> exporter (`api/src/lib/ugp`). In the monorepo it is resolved directly. For a
> standalone deployment, vendor it first (`cp -r ../../api/src/lib/ugp src/vendor/ugp`)
> so the CLI is self-contained; `npm ci` then installs its runtime deps
> (`neo4j-driver`, `tar-stream`, `@qdrant/js-client-rest`).

## Commands

```bash
# Validate a package — checksums, manifest, nodes, relationships, vectors.
# No DB connection required.
node bin/unpa-import.js validate ./export.ugp.tar.gz --verbose

# Dry-run diff against the target (TASK-EXP-006)
node bin/unpa-import.js plan ./export.ugp.tar.gz --conflict=skip

# Execute the import (TASK-EXP-007+)
node bin/unpa-import.js apply ./export.ugp.tar.gz --conflict=skip --yes

# Show a prior import's report (TASK-EXP-010)
node bin/unpa-import.js report <importId>
```

`validate` exits `0` when the package is valid (warnings allowed) and `1` on any
integrity error — suitable for CI gating.

## Configuration

Precedence: **CLI flags > config file > environment variables > defaults**.

### Environment (see `.env.example`)

| Var | Default | Purpose |
|-----|---------|---------|
| `MEMGRAPH_URI` | `bolt://localhost:7687` | Target Bolt URI |
| `MEMGRAPH_USER` / `MEMGRAPH_PASSWORD` | — | Target credentials |
| `QDRANT_URL` | `http://localhost:6333` | Target Qdrant |
| `QDRANT_API_KEY` | — | Qdrant auth (if enabled) |
| `TARGET_API_URL` / `TARGET_API_TOKEN` | — | Catalog channel for executable graphs |

### Config file

```bash
node bin/unpa-import.js apply pkg.ugp.tar.gz --config=import.config.json
```

```json
{
  "memgraph": { "uri": "bolt://prod:7687", "user": "memgraph", "password": "..." },
  "qdrant": { "url": "http://prod:6333" },
  "conflict": "skip",
  "batchSize": 500
}
```

## Conflict policies

- `skip` — target wins; skip an incoming node if it already exists (default)
- `overwrite` — incoming wins; replace the target node's properties
- `newer-wins` — compare `updatedAt`; keep whichever is newer

## Standalone deployment (without the monorepo)

The importer shares one serialization library with the exporter (`api/src/lib/ugp`).
For a target server that has no monorepo checkout, **vendor** that library into
this package so it is self-contained.

### Option A — clone + vendor (recommended)

```bash
# On a build machine that HAS the monorepo:
cd tools/unpa-import
npm run vendor          # copies api/src/lib/ugp → src/vendor/ugp
npm ci                  # installs UGP runtime deps (neo4j-driver, tar-stream, qdrant)
npm run standalone-check # proves the CLI resolves everything without the repo

# Then copy the whole tools/unpa-import folder (with src/vendor + node_modules) to the target.
./bin/unpa-import.js validate package.ugp.tar.gz
./bin/unpa-import.js apply package.ugp.tar.gz --yes
```

### Option B — pre-built tarball (`npm pack`)

```bash
cd tools/unpa-import
npm pack                # `prepack` runs `vendor` automatically → unpa-import-1.0.0.tgz

# Transfer the .tgz to the target, then:
tar -xzf unpa-import-1.0.0.tgz && cd package
npm ci --omit=dev
node bin/unpa-import.js --help
```

`src/vendor/` is git-ignored — it is a build artifact, regenerated by `npm run vendor`.
`STANDALONE=1` disables the in-repo fallback so a missing vendored copy fails loudly
(this is what `npm run standalone-check` asserts).

### End-to-end test

`npm run e2e` runs the full cycle against the local dev stack: create test data →
export via the graph-transfer API → delete the source (simulating a clean target)
→ `validate` → `plan` → `apply` → verify re-materialization → cleanup. Requires the
UNPA API (:3010), Memgraph (:7687) and target creds in the environment.

## Package format (UGP)

`*.ugp.tar.gz` containing `package/manifest.json`, `package/graph/nodes.jsonl`,
`package/graph/relationships.jsonl`, `package/vectors/<collection>.jsonl` and
`package/checksums.sha256`. Node identity follows the per-label Identity Map;
Qdrant points carry a reverse payload link to node identity. See
`api/src/lib/ugp` for the authoritative format.
